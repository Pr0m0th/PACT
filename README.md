# PACT – Prototype of an Autonomous Campus Taxi

## Overview

PACT (Prototype of an Autonomous Campus Taxi) is an autonomous mobility platform designed to explore intelligent transportation solutions for campus environments. The system integrates computer vision, embedded control systems, wireless communication, and real-time obstacle detection to enable autonomous navigation and decision-making.

The project combines a Raspberry Pi-based vision module with STM32 and ESP32 microcontrollers to create a modular architecture capable of detecting obstacles, processing environmental information, and executing motor control actions.

---

## Objectives

- Develop a low-cost autonomous mobility prototype.
- Implement real-time obstacle detection using computer vision.
- Integrate embedded controllers for navigation and motor control.
- Enable communication between processing and actuation subsystems.
- Demonstrate safe autonomous movement in a campus environment.

---

## System Architecture

### Raspberry Pi 4
- Camera-based obstacle detection
- Edge detection and image processing
- Environment monitoring
- Decision generation

### STM32 Controller
- Main system controller
- Command processing
- System coordination and control logic

### ESP32 Module
- Receives navigation commands
- Controls motor actuation
- Interfaces with motor drivers

### Mobility Platform
- Four-wheel drive system
- Dual motor driver architecture
- Real-time movement execution
